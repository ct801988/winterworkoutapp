# Winter Strong — iPhone workout tracker

A fully functional **offline-capable Progressive Web App (PWA)** built for the original **20-week phased Winter Strength & Physique Program**. No developer account, App Store approval, subscription, or server-side database required.

## Included

- All **20 weekly assignments**, **5 four-week phases** and **100 exact exercise tables** extracted from your original Word workbook: 620 prescribed exercises, including the advanced Saturday core workouts.
- Week-by-week rep bands, work set counts, target RIR, deloads, and bench/squat/pull-up progression.
- Per-set tracking of actual **weight/load, reps or seconds**, next workout goal, substitutions, and actual RIR.
- Intelligent guidance using the previous logged session for the *same exercise and substitute*, including whether to maintain weight or attempt a load increase.
- Wednesday and Saturday cardio options (including Yoga X, X Stretch, and Kenpo X), mobility checklist, check-ins, and scoreboards.
- Saves entries automatically **on the same device** through browser storage; installed PWA works offline after the initial online load.
- Export/import entire log as a JSON backup and export rows as CSV.

## The easy way to put it on an iPhone (GitHub Pages)

You must publish the files on an **HTTPS website**. Opening `index.html` inside the iPhone Files app won't give you a proper installed app or reliable persistent storage.

1. Open [github.com](https://github.com) and create a free account or sign in.
2. Create a **new public repository**, e.g. `winter-strong`. GitHub Pages on free GitHub accounts supports public repositories. **Only the code is public**, not the workout data you enter in the app; however, do not put personal workout logs or exported backups in the repository.
3. Click **Add file → Upload files**. Upload `index.html`, `styles.css`, `app.js`, `program.js`, `manifest.webmanifest`, `sw.js`, **and the entire `icons/` folder**. You may need to unzip the project on a computer first. Commit the files to your repository root. (The ZIP already includes everything needed to run the app.)
4. In GitHub: **Settings → Pages → Build and deployment → Deploy from a branch**. Choose `main` and `/(root)`, then save.
5. Wait for GitHub to display your site's URL, usually `https://YOUR-USERNAME.github.io/winter-strong/`.
6. On your **iPhone in Safari**, open that HTTPS URL. Tap **Share → Add to Home Screen → Add**.
7. Launch **Winter Strong** from the new Home Screen icon. Log a trial set. Turn Airplane Mode on and confirm it still opens.

You can also deploy this same folder to any HTTPS static host (Cloudflare Pages, Netlify, etc.). No `npm` or build command required.

## Important data behavior

- The app stores data **only in your phone's browser/app website storage**. It will not sync automatically between iPhone, iPad, laptop, or private browsing windows.
- Changes made to code on GitHub update the app code, but **not** user data. Service worker cache may take a reload to update.
- Clearing Safari website data, reinstalling the app, switching phones, private mode, or storage eviction may erase the workout log. **Export a JSON backup regularly** in Settings. Save it in iCloud Drive or another folder you control; to restore, use **Restore backup** in Settings.
- Hosting on a public GitHub Pages repository makes the app's source code publicly readable. Your locally entered workouts do **not** get uploaded by the app.

## Training guardrails

The programming follows the source workout guide. An earned increase means completing **all work sets** at the top of the previous week's rep range with controlled form and appropriate reps in reserve. Progress instructions are suggestions, not safety guarantees. Painful pinching, new weakness, or a sensation of instability merits stopping the provoking movement and getting assessed; a historical unassessed shoulder injury with persistent symptoms warrants an appointment regardless of app recommendations.

## Local testing (on a computer)

From this directory run `python3 -m http.server 8000`. Open `http://localhost:8000` in a web browser. Browser storage works locally. Offline caching is also supported on localhost after initial load. Do **not** rely on opening the HTML as `file://` for persistent app behavior.

## Project files

- `index.html` — document and app shell
- `styles.css` — responsive layouts and mobile visuals
- `program.js` — exact planned workouts and weekly progression rules (autogenerated from original Word document)
- `app.js` — logic, local storage, automatic workout log, export/import
- `sw.js` — service worker for offline caching
- `manifest.webmanifest` and `icons/` — iOS/Android Home Screen support
